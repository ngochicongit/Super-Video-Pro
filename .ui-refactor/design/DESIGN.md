# Super Video Pro design DNA

The product uses a compact, dark desktop-editor language: navy surfaces, teal primary actions, restrained gradients, thin blue-gray borders, and dense professional controls. UI refactors must preserve this language.

Use the 4/8/12/16/24 spacing scale and 7/11/16 radius scale. Interactive controls need a visible keyboard focus ring and a minimum 32 px hit target. Motion must respect `prefers-reduced-motion`. Prefer changes to shared tokens and primitives over isolated exceptions.
