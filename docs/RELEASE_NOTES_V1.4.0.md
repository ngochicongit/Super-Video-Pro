# Super Video Pro 1.4.0

## New

- Add up to eight independent logo overlays to a video composition.
- Configure static, bouncing, horizontal or vertical movement per logo.
- Control position, size, opacity, hue, background color, background opacity and padding.
- Configure movement speed and a fade-in effect for static logos.

## Validation

- Logo settings are schema-validated across the isolated renderer-to-main IPC boundary.
- FFmpeg integration tests render and inspect real multi-logo output frames.

## Distribution

- Windows NSIS installer for local distribution.
- External publication is separate from local installer generation.
